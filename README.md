## <img src="https://raw.githubusercontent.com/Elhsup/Galeria-de-Stickers/main/imagenes/animados/reacciones-gif/gif-meme-john-travolta-confundido.png" width="50" alt="meme-travolta-pulp-fiction">¿Para qué sirve este repositorio? (La innovación)

En la mayoría de las páginas de stickers e internet, **no te permiten copiar y pegar directamente el código adaptado para GitHub o .md**, tienes que estar arrastrando el mouse para seleccionar líneas de código html. 

Este repositorio es **pionero en resolver esto (CREO)**:
1.  **Almacenamiento Seguro (Anti-Enlaces Rotos):**  Si usas enlaces externos de otras páginas, tal vez con el tiempo se caigan o borren la imagen, rompiendo tu README. Aquí guardamos físicamente cada sticker en el repositorio para que tu enlace funcione **para siempre** (a menos que borres el archivo físico de la carpeta `imagenes/` y hagas push, lo cual rompería el enlace).
2. **Formateo Automático a HTML:** GitHub no permite redimensionar imágenes con Markdown tradicional `![](...)`. Para usar un sticker gigante como un emoji chiquito, es obligatorio usar la etiqueta HTML `<img>`. ¡Un script automatiza esto por ti convirtiendo cualquier enlace en HTML limpio en un segundo y subiendolo en el repo sin que hagas nada!
3. **Botón de Copia en un Click:** Gracias al catálogo, no tienes que seleccionar texto con el mouse. GitHub te mostrará un botón de **"Copy"** directo al lado de cada tamaño.

## <img src="https://raw.githubusercontent.com/Elhsup/Galeria-de-Stickers/main/imagenes/animados/memes-gif/club-penguin-pinguino-limpiando-trapeador.png" width="100" alt="black penguin from Club Penguin holding a mop">  Guía de Uso del Catálogo

Usar este almacén para decorar tus proyectos es sumamente fácil y rápido. Sigue estos pasos:

### Paso 1: Explora el Catálogo
Entra a nuestro **[Catálogo General](./catalogo/README.md)** y navega hacia la categoría que más te guste (por ejemplo, *Memes Animados*).

### Paso 2: Elige tu Sticker y tu Tamaño
Busca el sticker que quieras usar. Verás una vista previa y tres opciones de tamaño listas para ti:
*  <img src="https://raw.githubusercontent.com/Elhsup/Galeria-de-Stickers/main/imagenes/animados/memes-gif/emoji-nerd.png" width="30" alt="meme de de echo">   **30px:** Tamaño mini (ideal para meterlo dentro de párrafos de texto como un emoji fluido).

*  <img src="https://raw.githubusercontent.com/Elhsup/Galeria-de-Stickers/main/imagenes/animados/memes-gif/emoji-nerd.png" width="50" alt="meme de de echo">   **50px:** Tamaño medio (perfecto para listas, viñetas o tarjetas).

*   <img src="https://raw.githubusercontent.com/Elhsup/Galeria-de-Stickers/main/imagenes/animados/memes-gif/emoji-nerd.png" width="100" alt="meme de de echo">  **100px:** Tamaño grande (ideal para encabezados o destacar secciones).

### Paso 3: Copia con un solo Click
Pasa el mouse sobre el bloque de código del tamaño que prefieras y haz clic en el botón **"Copy"** que aparece automáticamente a la derecha en GitHub.

### Paso 4: ¡Pégalo en tu Markdown!
Abre cualquier archivo `.md` (tu README, un perfil, un issue o una discusión de GitHub) y pega el código donde quieras.

##  <img src="https://raw.githubusercontent.com/Elhsup/Galeria-de-Stickers/main/imagenes/animados/memes-gif/meme-nino-comiendo-cuchara-mirada-fija.png" width="50" alt="kid"> ¿Cómo funciona los Emojis HTML?

Convertir una imagen o GIF en un emoji ajustable es muy sencillo. Tomamos la dirección de internet directa del archivo (**GitHub Raw Link**) y la envolvemos en una etiqueta HTML especificando el ancho (`width`):

```html
<!-- Esto hace que un sticker grande se comporte como un emoji dentro de tu texto -->
img src="https://raw.githubusercontent.com/Elhsup/Galeria-de-Stickers/main/imagenes/animados/memes-gif/pepe-descubierto.png" width="100" alt="me-atraparon">

```

## <img src="https://raw.githubusercontent.com/Elhsup/Galeria-de-Stickers/main/imagenes/animados/reacciones-gif/pepe-pensando.png" width="50" alt="pepe-thin"> ¿Cómo funciona la Galería?

La forma en que GitHub renderiza el Markdown nativo no permite cambiar el tamaño de una imagen tradicional. Para lograr que una imagen se comporte como un **emoji chiquito y estilizado**, usamos el truco definitivo: la etiqueta HTML `<img>` con anchos fijos.



## <img src="https://raw.githubusercontent.com/Elhsup/Galeria-de-Stickers/main/imagenes/estaticos/reacciones/pepe-sorprendido.png" width="40" alt="pepe :0"> La Regla de Oro: ¡No Borres las Fotos!
Este repositorio actúa como un **servidor de almacenamiento gratuito** a través de los enlaces de **GitHub Raw** (`raw.githubusercontent.com`) . 
> <img src="https://raw.githubusercontent.com/Elhsup/Galeria-de-Stickers/main/imagenes/animados/memes-gif/pepe-arma.png" width="30" alt="pepe-gun"> **MUY IMPORTANTE**: Una vez que al subir una imagen y se genere el enlace, **jamás se borrara, movera ni renombrara** en el repositorio. Si se borra la imagen física de la carpeta `imagenes/`, el enlace de internet se romperá de inmediato y la imagen aparecerá como un **icono roto o dañado** en todos los perfiles de GitHub donde la hayas pegado. ¡Cuida esta mini base de datos!
