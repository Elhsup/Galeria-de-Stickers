## <img src="https://raw.githubusercontent.com/Elhsup/Galeria-de-Stickers/main/imagenes/animados/reacciones-gif/pepe-pensando.png" width="50" alt="pepe-thin"> ¿Cómo funciona la Galería?

La forma en que GitHub renderiza el Markdown nativo no permite cambiar el tamaño de una imagen tradicional. Para lograr que una imagen se comporte como un **emoji chiquito y estilizado**, usamos el truco definitivo: la etiqueta HTML `<img>` con anchos fijos.

En nuestro catálogo encontrarás tres tamaños estándar optimizados para cada emoji:
* <img src="https://raw.githubusercontent.com/Elhsup/Galeria-de-Stickers/main/imagenes/animados/memes-gif/emoji-nerd.png" width="30" alt="meme de de echo">  **30px (Mini)**: Ideal para meterlo dentro de tus frases y texto fluido.
* <img src="https://raw.githubusercontent.com/Elhsup/Galeria-de-Stickers/main/imagenes/animados/memes-gif/emoji-nerd.png" width="50" alt="meme de de echo">  **50px (Medio)**: Perfecto para listas con viñetas, secciones o títulos secundarios.
* <img src="https://raw.githubusercontent.com/Elhsup/Galeria-de-Stickers/main/imagenes/animados/memes-gif/emoji-nerd.png" width="100" alt="meme de de echo">  **100px (Grande)**: Para destacar secciones importantes, banners o despedidas.

### <img src="https://raw.githubusercontent.com/Elhsup/Galeria-de-Stickers/main/imagenes/estaticos/reacciones/pepe-sorprendido.png" width="40" alt="pepe :0"> La Regla de Oro: ¡No Borres las Fotos!
Este repositorio actúa como un **servidor de almacenamiento gratuito** a través de los enlaces de **GitHub Raw** (`raw.githubusercontent.com`) . 
> <img src="https://raw.githubusercontent.com/Elhsup/Galeria-de-Stickers/main/imagenes/animados/memes-gif/pepe-arma.png" width="30" alt="pepe-gun"> **MUY IMPORTANTE**: Una vez que subas una imagen y generes su enlace, **jamás la borres, muevas ni renombres** dentro de tu repositorio. Si borras la imagen física de tu carpeta `imagenes/`, el enlace de internet se romperá de inmediato y la imagen aparecerá como un **icono roto o dañado** en todos los perfiles de GitHub donde la hayas pegado. ¡Cuida esta mini base de datos! (aunque el plan es que yo administre esto pero sirve para entender este repo)
