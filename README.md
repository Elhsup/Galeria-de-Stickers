# Galería de Stickers

Galería de Stickers — colección pública de stickers y emojis aprobados por la comunidad.

Estructura principal:
- catalogo/ : versiones aprobadas (v1.png, thumb.png, manifest_public.json)
- contribucion/ : plantillas e instrucciones para enviar stickers
- raw/ : originales privados (no subir al repo)

Cómo usar:
- Imágenes públicas: https://raw.githubusercontent.com/TU_USUARIO/REPO/main/catalogo/<SLUG>/v1.png
- Lee CONTRIBUTING.md para saber cómo enviar y revisar contribuciones.

Título y descripción en español; todo el contenido y las instrucciones están en español.
